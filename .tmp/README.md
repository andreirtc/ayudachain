# Preserved working snapshots

These files were included at the maintainer's explicit request to publish all Git-visible uncommitted work from `feat/five-role-mvp`.

The build directories and `source.tar` are historical source snapshots, not the current application. Use the repository-root `frontend/`, `backend/`, `contracts/` and `docs/` for development. Copies of instructions and validation records inside snapshots describe their captured state and do not supersede the root documents.

Other files are local maintenance scripts, synthetic assets and read-only screen-review captures. Script paths and environment assumptions may be specific to the original workstation; inclusion does not make these scripts supported setup commands. Follow the root `CONTRIBUTING.md` and `docs/guides/local-mvp.md` for setup.

Historical snapshots retain their existing whitespace, including trailing spaces and end-of-file blank lines. The publication whitespace check passed for the active frontend changes, current documentation, design assets and showreel; the full archive check reports those preserved snapshot findings.

Git-ignored credentials, runtime databases, dependencies and build outputs are excluded. Runtime logs referenced by historical reports may remain local and unavailable in a fresh checkout.
