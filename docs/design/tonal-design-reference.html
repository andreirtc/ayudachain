AyudaChain Tonal

This develops Proposal H into a complete design system. It is built on Material 3, the design language most Android phones in the Philippines already use, set in Open Sans. It includes three colour palettes in light and dark, three logo concepts, and screens for all five roles. Use the controls to re-colour every mockup on the page.

Logos

There are three concepts. Each one works as a full lockup, an app icon and a single-colour mark down to 16px. The wordmark is set in Open Sans Bold, so it matches the interface. None of them uses government seals, flags or agency marks.

Colour palettes

Each palette is a complete Material 3 tonal scheme in light and dark. Status colours (success, warning, error, simulated) are shared across all three, so a “Does not match” result looks the same whichever palette is chosen. The contrast column is calculated live from the values shown.

Household (Beneficiary)

Four screens follow a household from approval to confirming what they received. The bottom bar has four destinations, and the next step is always the first thing on screen. English and Filipino are both shown.

Barangay Officer

Barangay staff work in the field on phones. The claim response fits on one screen, and the segmented button makes the endorse choice explicit. A floating button starts assisted registration, their most common create action.

DSWD Officer

On desktop, the navigation rail, list pane and detail pane follow the Material 3 list-detail layout. On a phone the same screen collapses to list, then detail. Flags appear as a Material 3 banner at the top of the case: an icon, a sentence and actions above a divider, with no coloured box. Integrity results are plain status rows.

Implementation

This changes presentation only. Routes, permissions, API calls, schema, the contract and hashing stay as they are.

  • Tokens: the role tokens above (--md-sys-color-*) replace the hard-coded values in frontend/app/mvp.css. The light and dark schemes switch with prefers-color-scheme.
  • Fonts: Open Sans and Source Code Pro load through next/font/google, which is part of Next.js and needs no new dependency.
  • Components: build these as plain CSS on the existing React components. Material Web would be a new dependency, so it needs your approval first.
  • Navigation: the rail on desktop and the bottom bar on phones both come from the existing workspaces.ts list. Households and barangay staff get at most four bottom destinations. Their other sections stay reachable from Home.
  • Logo: once you pick one, the chosen mark replaces the current shield block in Workspace.tsx and the /mvp entry page, and is exported as SVG, favicon and app icon.

All households, officers, codes, counts and amounts are synthetic. Names come from backend/scripts/seed_mvp.py. The amount follows the existing wage formula, using an example ₱645 daily wage. No government seal or agency logo is used.
