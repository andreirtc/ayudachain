## Ano ang kaya nating i-defend?

Original-backed records, human review, documented amounts, assigned sessions, once-only recorded handover, recipient reports, actual local-chain checks at independent verifier. Quote only the completed results in the linked readiness ledger. Huwag pagsamahin ang separate failed runs/reruns para magmukhang isang green suite.

## Ano ang hindi pa puwedeng i-claim?

- Secure real-user login/accountability: wala pang authentication sa current MVP.
- Official current ECT compliance, government endorsement o COA certification.
- Live National ID/SMS integration; simulated ang mga ito.
- Offline payout, full liquidation/advances/returns o bank money transfer.
- Proven savings, selling price, customer adoption o production capacity.
- Physical-phone/camera validation o measured citizen comprehension; browser viewport checks are narrower evidence.

## Ano ang kailangan gawin ng team?

Read beginner guide, rehearse script aloud, choose speakers, verify slide claims and copy fallback files to the venue machine. Huwag mag-enter ng real citizen data. Huwag mag-repeat ng recorded payout para lang may live action. Sa Auditor, puwedeng mag-fresh check; report the actual result.

Keep laptop powered and the current independent local chain alive. Earlier chain interruption is recorded honestly; old proof results are historical. Bagong isolated rehearsal ang current lab, hindi invented recovery.
